# Form Login — ORBITA POS Cloud POS

Halaman portal autentikasi & login resmi untuk **ORBITA POS** (Grill, Bar & Lounge).

## Fitur Utama Form Login
1. **Dua Mode Autentikasi**:
   - Mode 1: **Email & Kata Sandi** (dengan fitur intip kata sandi).
   - Mode 2: **PIN Cepat Kasir (6-Digit)** dengan visual dots & virtual numeric keypad layar sentuh.
2. **Akun Demonstrasi 1-Klik**:
   - 👑 **Super Admin / Owner**: `director@orbita.bar` (PIN: `889900`)
   - 💼 **Manajer Operasional**: `bar.manager@orbita.bar` (PIN: `556677`)
   - 💳 **Kasir Shift**: `cashier@orbita.bar` (PIN: `123456`)
3. **Pemilihan Cabang / Outlet Aktif** (Orbita Lounge SCBD, Orbita Rooftop Bali, Orbita Surabaya).
4. **Indikator Live Status**: Menampilkan status konektivitas server secara interaktif.
5. **Auto Redirect**: Setelah autentikasi berhasil, pengguna langsung diarahkan ke aplikasi utama di [`../orbita-cloud-pos/index.html`](../orbita-cloud-pos/index.html).
6. **Bypass Button**: Tombol shortcut untuk penguji/developer membuka aplikasi tanpa proses login.

## Menjalankan Halaman
Cukup buka file `index.html` langsung di browser Anda (atau via server lokal / GitHub Pages).
